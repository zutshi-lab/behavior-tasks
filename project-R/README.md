## Task files

- **Arduino:** Code for controlling the task.
- **Bonsai:** Workflows for tracking and task communication.
- **Settings:** Configuration files used to run the task.

## Before running a session

1. Review the protocol and the animal’s previous session notes.
2. Confirm the task settings and code uploaded to the Arduino.
3. Complete the equipment checks described in the protocol.
4. Confirm the data save location.

## After each session

Update the tracking sheet with **session results, observations,
equipment problems, and the data location**.
Copy all files from Documents\Videos to the relevant folders on the computer

## Making code changes

Create a **branch**, edit and test your changes, then open a
**pull request** for review before merging into `main`.
